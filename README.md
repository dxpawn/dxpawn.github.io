# dxpawn.github.io

This repo hosts the **lactose intolerance 🤯** blog via **GitHub Pages** + **Jekyll**.

## Local preview

If you have Ruby + Bundler installed:

```bash
gem install bundler jekyll
bundle exec jekyll serve
```

## Publishing

In the repo settings:

- Settings → Pages
- Source: Deploy from a branch
- Branch: `jekyll-blog-starter` (or merge to default branch)
- Folder: `/ (root)`
